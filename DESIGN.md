# Design System

## Theme

Restrained dark product interface for focused laptop use. Near-black neutral surfaces carry the UI; terracotta is reserved for primary actions, active state, and concise status.

## Typography

Inter or system sans. Product-scale hierarchy: 20px view title, 14px body, 12px supporting text, 11px metadata. Avoid decorative display type and excessive all-caps labels.

## Color Tokens

- Background: `#0c0c0f`
- Raised surface: `#17171c`
- Interactive surface: `#202027`
- Primary text: `#f2f2f4`
- Secondary text: `#b8b8c2`
- Muted text: `#8a8a96`
- Accent: `#e0906a`
- Success: `#7bd0a0`
- Danger: `#e07b7b`

## Components

- Primary action: solid accent, concise verb, 40px minimum height.
- Secondary action: outlined neutral control.
- Inputs: one consistent dark field treatment with visible focus ring.
- Import drop zone: one purposeful dashed area with accepted file types and upload status.
- Memory rows: flat grouped list rows, never stacks of cards.

## Layout & Motion

Use a compact rail, a contextual secondary panel only where useful, and a single centered task column. Motion is limited to 160–220ms feedback; respect reduced-motion settings.
