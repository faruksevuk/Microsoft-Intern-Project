# Product

## Register

product

## Users

One technically curious owner using a private local second brain on a laptop. The core jobs are asking grounded questions, adding a source quickly, and understanding what the system did without reading implementation details.

## Product Purpose

Make a small local model useful and trustworthy through retrieval, memory maintenance, and explicit safeguards. Success means the owner can add knowledge, ask a question, and confidently understand the answer's provenance and limits.

## Brand Personality

Calm, precise, candid. It should feel like a dependable personal tool, not a futuristic AI demo.

## Anti-references

Avoid decorative glassmorphism, exaggerated gradients, dashboard-card clutter, generic "AI copilot" copy, and motion that delays work.

## Design Principles

1. Put the current task ahead of system novelty.
2. Reveal system complexity only when it helps a decision.
3. Make local-first and verification visible through plain language, not spectacle.
4. Prefer fast, familiar controls over invented interactions.
5. Show clear next actions for empty, loading, error, and success states.

## Accessibility & Inclusion

Target WCAG AA contrast, visible keyboard focus, 44px touch targets where practical, readable Turkish and English copy, and reduced-motion support.
